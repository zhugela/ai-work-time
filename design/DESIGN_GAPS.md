# DESIGN_GAPS · 设计缺口与待评审项

> 本文档记录当前 DESIGN.md 在原型落地过程中暴露的不确定点、模糊点和待评审项，用于设计/产品/技术三方对齐。

---

## G-01 顶部"当前账本切换器"的呈现位置
- **现状**：未明确放在顶部栏左侧 vs 侧边栏顶部
- **建议**：放侧边栏顶部（与 PRD 3.2 B04 切换账本呼应）
- **影响范围**：登录后所有页面的整体布局
- **待定**：评审会确认

## G-02 收支录入页是模态弹窗还是独立页
- **现状**：PRD 给出接口但未规定 UI 形态
- **建议**：独立页（信息密度大），从侧边栏"快速录入"进入
- **影响范围**：G-03 弹窗列表

## G-03 弹窗 vs 抽屉（Drawer）的使用边界
| 场景 | 建议 |
|---|---|
| 导入导出、确认删除 | 居中 Modal |
| 分类管理新增 | 右侧 Drawer |
| 月份选择 | 居中 Modal |
| 录入表单（可选项） | 居中 Modal 或右侧 Drawer |

## G-04 收支类型（收入/支出）的色彩编码
- **建议**：收入=绿、支出=红、转账=蓝（待评审是否启用蓝）
- **决定**：启用 income-500 / expense-500；TRANSFER 暂不在本期

## G-05 分类图标的选型
- **建议**：用 emoji（如 🍔 🚇 🛒）作为分类图标，与 PRD"分类含图标"一致
- **备选**：用 Lucide 图标 + 自定义颜色
- **决定**：使用 emoji（轻量、识别度高、无需图标库）

## G-06 月度预算"执行进度条"颜色
- **建议**：
  - < 80%：品牌色 brand-500
  - 80~100%：warn-500
  - ≥ 100%：expense-500
- **待评审**：阈值是否可配置

## G-07 趋势图（6/12 月）的图表库
- **候选**：纯 SVG 手绘、ECharts、Chart.js
- **建议**：纯 SVG（不引入第三方依赖，符合"私有化部署"轻量理念）
- **决定**：纯 SVG

## G-08 分类占比图（饼图 vs 横向条形）
- **建议**：横向条形图（top10 + 其他）
- **理由**：分类名长，横向条形更易读；且无需颜色图例

## G-09 表格分页
- **现状**：每页 20/50/100
- **决定**：默认 20，跳页 + 上下页

## G-10 移动端适配
- **现状**：本期以 PC 桌面为主，移动端未规划
- **决定**：移动端在二期
- **影响**：本期不投入响应式断点细节

## G-11 主题切换默认值
- **建议**：跟随系统 `prefers-color-scheme`
- **决定**：实现 + 用户可手动覆盖

## G-12 占位与加载态
- **建议**：列表用骨架屏、表单按字段级 spinner
- **决定**：实现骨架屏

## G-13 错误提示
- **建议**：表单字段级红字 + 顶部 toast
- **决定**：实现

## G-14 图标库
- **建议**：Lucide（CDN 内联或下载到本地）
- **决定**：用 inline SVG，不依赖外部 CDN

## G-15 字体加载
- **建议**：系统字体优先，Inter 作为可选增强
- **决定**：系统字体栈 + 中英文混排
