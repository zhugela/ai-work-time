## 1. 本期实现清单（In-Scope）

### 1.1 账号体系（Must）
- [x] 用户注册（用户名/密码/手机或邮箱）
- [x] 用户登录（账号密码 + Token）
- [x] Token 维持与刷新
- [x] 修改密码 / 修改昵称
- [x] 退出登录（Token 失效）
- [x] 登录失败锁定（5 次 / 30 分钟）

### 1.2 账本管理（Must）
- [x] 创建账本
- [x] 账本列表 / 详情
- [x] 切换当前账本
- [x] 归档 / 恢复账本
- [x] 单用户最多 50 个账本

### 1.3 分类管理（Must）
- [x] 系统预置分类（15 支出 + 8 收入）
- [x] 自定义分类（增/改/删）
- [x] 单账本最多 100 个自定义分类

### 1.4 收支录入（Must）
- [x] 新增支出 / 收入
- [x] 修改 / 软删除
- [x] 按日期倒序分页列表（支持日期/分类筛选）
- [x] 详情查询
- [x] 支付方式枚举

### 1.5 预算管控（Must）
- [x] 设置 / 更新月度预算
- [x] 查看月度执行进度
- [x] 超预算实时预警（响应字段标记）

### 1.6 统计报表（Must）
- [x] 月度收支汇总（收入/支出/结余）
- [x] 分类支出占比（top10 + 其他）
- [x] 收支趋势（近 6 / 12 个月）

### 1.7 数据导入导出（Must + Should）
- [x] 下载导入模板
- [x] Excel 批量导入（≤ 5000 行 / 5MB）
- [x] 导出收支明细
- [x] 导出月度统计报表

### 1.8 系统管理（Could）
- [x] 系统预置分类初始化
- [x] 平台规模统计
- [x] 启停用户账号
- [x] 审计日志查询（保留 180 天）

### 1.9 非功能（Must）
- [x] HTTPS + Token 鉴权
- [x] BCrypt 密码加密
- [x] 统一响应包装 `{code, msg, data}`
- [x] 统一异常处理
- [x] Docker 化部署

## 2. 本期明确不做清单（Out-of-Scope）

> 以下功能**本期明确不做**，避免需求蔓延。所有"不做"项均需业务方在二期立项后重新评估。

### 2.1 多端协作类
- ❌ 多用户共享账本 / 协作记账
- ❌ 家庭成员权限分配
- ❌ 账本邀请码 / 加入申请

### 2.2 财务进阶类
- ❌ 复式记账（借贷记账法）
- ❌ 多币种实时汇率换算
- ❌ 转账记录（内部账户间转账）
- ❌ 资产负债 / 净值追踪
- ❌ 信用卡账单解析与匹配

### 2.3 数据采集类
- ❌ 票据 OCR 识别
- ❌ 微信 / 支付宝账单自动同步
- ❌ 短信账单识别
- ❌ 银行流水导入（OFX/QFX）

### 2.4 智能化类
- ❌ AI 自动分类
- ❌ 消费习惯画像
- ❌ 财务建议 / 异常消费提醒（基于 ML）

### 2.5 通知与触达类
- ❌ 微信 / 邮件 / 短信提醒
- ❌ App Push 通知
- ❌ 周期性报表邮件订阅

### 2.6 第三方登录类
- ❌ 微信扫码登录
- ❌ 支付宝授权登录
- ❌ Google / Apple 登录

### 2.7 客户端交付类
- ❌ 原生 iOS / Android APP
- ❌ 微信小程序
- ❌ Web 前端 UI
- ❌ 桌面客户端（Electron 等）

### 2.8 商业化类
- ❌ 订阅 / 付费墙
- ❌ 广告位
- ❌ 内购

### 2.9 运维 / 安全进阶类
- ❌ 双因素认证（2FA）
- ❌ 单点登录（SSO）
- ❌ 数据加密落盘
- ❌ 异地多活
- ❌ 灰度发布 / 蓝绿部署

## 3. 范围变更控制

1. 任何新增 In-Scope 项需经过 2 次需求评审并归档到 `docs/requirements/CHANGELOG.md`。
2. 任何"明确不做"项若被提出，需重新评估后单独排期。
3. PRD / Scope / AC 三份文档需同步更新并标注版本号。

## 4. 二期候选清单（仅记录，不承诺）

| 优先级 | 候选功能 | 备注 |
|---|---|---|
| 高 | 多用户共享账本 | 用户呼声最高 |
| 高 | 微信账单自动同步 | 数据迁移痛点 |
| 中 | 多币种 + 实时汇率 | 海外用户场景 |
| 中 | 票据 OCR | 提升录入效率 |
| 低 | AI 自动分类 | 差异化卖点 |
| 低 | 财务建议 | 增值服务 |
