## 二、BUG 清单与修复

### B-01 · 拖拽抖动残留
| 项 | 内容 |
|---|---|
| 位置 | `import-export.html` `uploadArea` |
| 现象 | dragenter 后立即 dragleave 会**不**触发 `dragover` 样式移除（高亮残留） |
| 根因 | dragenter / dragleave 在子元素冒泡时会**重复触发**，单次配对逻辑失效 |
| 修复 | 引入 `dragCounter` 计数器；进入+1，离开-1，== 0 时移除样式 |
| 文件 | [import-export.html:192-211](../prototype/import-export.html) |
| 状态 | ✅ 修复并通过单元级测试 |

### B-02 · 切换账本未联动
| 项 | 内容 |
|---|---|
| 位置 | 全局 `app.js` `setBook` |
| 现象 | 调用 `setBook('家庭账本')` 后，顶栏名称改了，**但**面包屑 / 账本卡片高亮 / localStorage 初始化流程未联动 |
| 根因 | ① `setBook` 仅设顶栏；② 页面初始化时强制 setBook 覆盖页面硬编码；③ 浏览器缓存了旧版 app.js（154 字符） |
| 修复 | ① 扩展 setBook：联动顶栏 + 卡片 + 面包屑 + localStorage + toast；② 初始化仅同步顶栏；③ 12 个 HTML 批量加 `?v=20260615` cache-bust |
| 文件 | [assets/app.js:88-117](../prototype/assets/app.js) + 12 个 HTML |
| 状态 | ✅ 修复并通过集成测试 |
