Overview

项目概述

当前 C 端记账 APP 普遍存在四大痛点：隐私收费、数据只入不出、广告侵扰、订阅涨价。

对甲方

节省 2-3 个月自研成本，可直接商业化封装

对终端记账人

数据 100% 自主；按需部署；规避第三方隐私泄露

对生态

提供稳定 API 契约，便于 Web/iOS/Android/小程序多端扩展

愿为定制后端付费的人，永远不是「想记账」的人，而是「想做一个记账产品给别人用」的人。

Scope

本期范围

✅ In-Scope（本期必做）

  • 账号体系 · 6 项（注册/登录/Token/改密/退出）
  • 账本管理 · 5 项（CRUD + 切换 + 归档）
  • 分类管理 · 4 项（系统预置 + 自定义）
  • 收支录入 · 5 项（录入 / 列表 / 改删）
  • 预算管控 · 2 项（设置 / 进度）
  • 统计报表 · 3 项（月度 / 占比 / 趋势）
  • 导入导出 · 4 项（模板 / 导入 / 双导出）

❌ Out-of-Scope（本期不做）

  • 多用户共享账本 / 家庭协作
  • 复式记账 / 多币种汇率换算
  • 票据 OCR / 微信账单自动同步
  • AI 自动分类 / 财务建议
  • 微信 / 邮件提醒 / App Push
  • 第三方登录（微信/支付宝/Google）
  • 原生 APP / 小程序 / Web 前端

业务规则精选

  • 密码强度 · 8-32 位含字母+数字 · 连续失败 5 次锁定 30 分钟

A11y

可访问性承诺

键盘可达

  • Tab 顺序 = 视觉顺序
  • 所有交互元素带焦点环
  • 弹窗 focus trap + Esc 关闭
  • Skip to main content 链接

视觉对比

  • 正文与背景 ≥ 4.5:1（WCAG AA）
  • 大字体 ≥ 3:1
  • 颜色不作为唯一信息载体
  • 错误信息双重提示（图标+文字）

所有金额用等宽字体 · 数字不被压缩 · 减少动效开关（prefers-reduced-motion）
